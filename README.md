## 关于体量 / 100MB 的说明（重要）

本库以「高密度、结构化、可检索」为核心，目前共 **20 章、约 20 万+ 汉字（约 250KB+）**，未刻意堆到 100MB。

原因：
- 纯文本 100MB ≈ 1500 万+ 汉字，远超一切大模型上下文窗口，会直接截断、无法使用。
- 体积若靠「注水/重复」撑大，只会污染语料，对模型推理与博弈反而有害。
- 真能用到「大体积」的场景是**微调/训练数据**，那是另一套工程（且涉及版权），与「喂给 DeepSeek 博弈」不同。

如确实需要更多内容，建议基于本库结构做**定向扩充**（更多案例、更多专项领域、更长练习），而非无脑堆字。
