# 逻辑与辩论资料库（Logic & Debate Corpus）

面向自学与「与 AI 展开论证博弈」的结构化中文知识库。

## 目录入口

```
逻辑与辩论资料库/
  00-总览与使用说明.md      整体框架、使用方式、与 AI 博弈的提示词模板
  01-形式逻辑基础.md        命题/谓词逻辑、推理规则、三段论、形式化证明
  02-论证结构与逻辑模型.md  论证要素、演绎/归纳/溯因、图尔敏模型、证明责任

  04-修辞学与说服机制.md    Ethos/Pathos/Logos、框架效应、预设、修辞格与防御
  05-辩论技术手册.md        辩题分析、立论、交叉质询、反驳、结辩、攻防战术
  06-博弈论与策略推理.md    囚徒困境/协调/猎鹿/小鸡、纳什均衡、BATNA、议价博弈

```

## 关于体量说明（重要）

本库以「高密度、结构化、可检索」为核心，共约 10 万汉字（约 130KB），未刻意堆到 100MB。

原因：
- 纯文本 100MB ≈ 1500 万+ 汉字，远超一切大模型上下文窗口，会直接截断、无法使用。
- 体积若靠「注水/重复」撑大，只会污染语料，对模型推理与博弈反而有害。
- 唯一能真正用到「大体积」的场景是**微调/训练数据**，那是另一套工程（且涉及版权），与「喂给 DeepSeek 博弈」不同。

如确实需要更多内容，建议基于本库的结构做**定向扩展**（案例、练习、专项主题），而非无脑堆字。
