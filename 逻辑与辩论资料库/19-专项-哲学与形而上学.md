# 19 · 专项领域：哲学与形而上学（Philosophy & Metaphysics）

> 哲学论证的特点：**抽象、概念分析、依赖思想实验与逻辑一致性**。
> 目标：学会「概念辨析 → 提出反例 → 思想实验 → 论证一致性」的哲学方法，并有能力在自由意志、意识、知识与实在等大问题上博弈。

---

## 1. 哲学论证的方法（概念分析四步）

1. **澄清概念**：把含糊的词（自由、意识、知识、因果）精确化。
2. **构造反例**：找一种满足条件但明显不对的情形。
3. **思想实验**：用假设情境检验推理的一致性。
4. **检验一致性**：看主张是否自相矛盾，或与其他确证信念冲突。

> **博弈要点**：哲学争论常输在**概念含混**。先把词定义清楚，谁定义得严谨、谁就占先机。

---

## 2. 核心哲学问题的论证地图

### 2.1 自由意志（Free Will）vs 决定论（Determinism）
- **硬决定论**：一切皆因果决定，无自由。
- **软决定论 / 相容论（Compatibilism）**：决定论与「自由」相容（自由=按自己意愿行动）。
- **自由意志论（Libertarianism）**：人有非决定的自由意志。
- **博弈点**：关键在于「自由」的定义；攻击对方定义的漏洞，或用「道德责任」反推，检验其后果是否可接受。

### 2.2 心身问题 / 意识（Consciousness）
- **物理主义**：意识=大脑过程。
- **二元论**：心灵与物质分离。
- **功能主义**：意识是功能/计算状态。
- **博弈点**：用「中文房间」「思想实验」检验「是否任何符号操作都能产生意识」；涉及「现象意识（qualia）」的难题。

### 2.3 知识论（Epistemology）——我们何以「知道」
- **怀疑论**：我们也许全被「恶魔/缸中之脑」欺骗，无法确知。
- **确证论**：何为被合理确证的信念（基础主义/融贯主义）。
- **Gettier 问题**：有证据、真、合理，但仍可能「只是碰巧对」——动摇「知识=确证的真信念」。
- **博弈点**：最有效的进攻是「构造一个满足你的标准、却不构成知识」的反例（Gettier 式）。

### 2.4 实在论 vs 反实在论（Reality）
- **实在论**：世界独立于观察存在。
- **观念论/反实在论**：实在依赖心智/语言。
- **博弈点**：用「不可前提」检验——（若反实在论，科学进步为何一致？）

## 3. 哲学常用论证技巧

| 技巧 | 说明 | 例子 |
|---|---|---|
| 归谬法 | 把前提推到荒谬 | 怀疑论→「那你也别相信一切」 |
| 反例法 | 找违背规则的情形 | Gettier 反例 |
| 思想实验 | 假设情境检验直觉 | 电车难题、中文房间、缸中之脑 |
| 概念分解 | 拆开一个词的所有含义 | 「自由」的多义 |
| 模态论证 | 用「可能/必然」推理 | 「或许不存在必然」 |
| 奥卡姆剃刀 | 不增加不必要的实体 | 去除多余假设 |

---

## 4. 哲学博弈的常见陷阱

- **概念滑坡**：把一个概念的日常义换成哲学义（偷换概念）。
- **无从检验**：哲学主张常不可经验验证，但要**检验逻辑一致性**与**反例**。
- **直觉依赖**：许多论证靠「直觉」，但直觉并不可靠（认知偏误）。
- **互不相通**：双方在不同语义下各说各话 → 先对齐定义。

## 5. 哲学博弈的提示词模板（对 AI）

```
【哲学主张】<粘贴一个「自由意志/意识/知识/实在」的立场或论证/请做哲学分析/>
请作为哲学家：
1) 澄清其中的【关键概念】（给出严格定义）；
2) 还原论证（前提-结论），指出推理跳跃；
3) 提出一个【反例/思想实验】，检验它是否自洽；
4) 给出论战中对立的【最强立场】（Steelman）；
5) 用【奥卡姆】与【一致性】标准评估，何者更节省/自洽？
```

## 6. 练习题库（哲学议题）

1. 「一切皆决定，所以没有自由」——用「相容论」说明它如何还可能成立。
2. 「AI 能通过图灵测试，所以有意识」——用「中文房间」反驳。
3. Gloria 的「Gettier 式」反例：如何破坏「知识=确证的真信念」？
4. 「缸中之脑」：为什么我们无法确知外部世界？如何回应（即便无法彻底反证）？
5. 设计一个思想实验，检验「人格同一性」（如忒修斯/传输）。
