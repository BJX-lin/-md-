# 13 · 专项领域：科学与伪科学（Science & Pseudoscience）

> 科学与伪科学之争，是「证据标准」之争。核心武器：**可证伪性、可重复性、证据分级、因果判断**。
> 目标：区分科学与伪科学，学会用「证据标准」与「可证伪性」来检验并瓦解伪科学论证。

---

## 1. 科学与伪科学的判别标准

| 判据 | 科学 | 伪科学 |
|---|---|---|
| 可证伪性 Falsifiability | 明确哪些证据能推翻它 | 无论发生什么都「自圆其说」 |
| 可重复性 Reproducibility | 可被独立重复验证 | 仅靠个别、无法复现的「案例」 |
| 可检验性 Testability | 可做出可验证的预测 | 预测模糊或不可验证 |
| 开放性 Openness | 欢迎证伪、公开方法与数据 | 回避审查、依赖「秘密/内幕」 |
| 渐进性 Self-correction | 根据证据修正理论 | 坚持原结论、否定不利证据 |

> **最强判别器**：问「什么证据会让你改变看法？」答不上来 = 疑似伪科学。

---

## 2. 伪科学论证的常见模式与击破

| 伪科学套路 | 结构 | 击破 |
|---|---|---|
| 诉诸「古已有之/自然」 | 古人/自然都这么用，所以有效 | 时间长短与疗效无关；天然≠安全/有效 |
| 轶事证据（anecdote） | 「我/我朋友用了就好了」 | 个案无对照、无统计，不能证明因果 |
| 诉诸「被主流压制」 | 「主流科学联合打压」 | 阴谋论不可证，且科学靠证据不靠多数 |
| 模糊预测 | 「能提升能量/频率」等不可测量词 | 要求可量化的检验标准 |
| 与科学术语混搭 | 用「量子」「磁场」「负离子」等词汇 | 术语是否被正确使用、是否有可证效应 |
| 选择性证据 / 德克萨斯神枪手 | 挑有利案例、事后编规律 | 指出分母缺失、事后编造 |
| 无法重复 | 只能成功、不能复现 | 要求独立重复实验 |

---

## 3. 证据分级（医学/科学证据的可靠性金字塔）

从强到弱：

1. **系统评价 / Meta 分析**（多个高质量研究的综合）
2. **随机对照试验（RCT）**（最可靠的单研究——有对照组、随机分配）
3. **队列研究 / 观察性研究**（能发现关联、难定因果）
4. **病例报告 / 案例系列**（提示、不可证因果）
5. **专家意见 / 轶事**（最弱）

> **博弈要点**：对任何「它有效/有害」主张，先问「处在证据金字塔哪一层？」若只有轶事/专家意见，则其证据力度远不足以支撑强主张。

---

## 4. 因果判断的标准（克里克/希尔标准 · 简版）

判断「A 导致 B」是否可信，看几条：

- **时序**：A 在 B 之前。
- **强度**：关联是否显著、可复现。
- **剂量-反应**：A 越多 B 越明显。
- **机制**：能否给出合理的生物学/物理机制。
- **一致性**：不同研究/人群是否一致。
- **排除替代解释**：是否考虑了混杂因素。

> **攻防**：质疑因果时，逐一攻击这几点；尤其「相关 ≠ 因果」与「是否有混杂变量」。

---

## 5. 与「阴谋论」博弈

阴谋论论证常是**溯因（最佳解释）的滥用 + 不可证伪的闭环**。应对：

1. **指出其不可证伪**：「无论发生什么，你都能解释成阴谋从属，这等于没有检验标准。」
2. **要求机制**：「谁、如何、为何能长期大规模隐瞒？执行这些人是怎么被协调与约束的？」
3. **证据分层**：「想要我信，请给出可核验的独立来源与证据链，而非‘感觉’。」
4. **奥卡姆剃刀**：「更简单、更能被常规证据解释的假设是什么？」
5. **对比解释强度**：「常规解释（市场、噪声、官僚系统）是否已充分说明现象？」

> **核心**：不要陷入「证明它不存在」的漩涡（举证责任在主张者），而应**要求主张方证明存在 + 提供可证伪机制**。

---

## 6. 科学辩论博弈的提示词模板（对 AI）

```
【科学主张】<粘贴一个「X 对 Y 有效/有害/引起 Z」的主张/>
请作为科学审评：
1) 这个主张可证伪吗？什么证据能推翻它？
2) 它的证据在【证据金字塔】哪一层？
3) 它是否混淆了【相关 vs 因果】？有无混杂变量？
4) 有没有可能的【替代解释】？
5) 若按【奥卡姆/希尔标准】评估，它的成立度如何？
6) 给出一个【可重复实验设计】来检验它。
```

---

## 7. 练习题库（科学议题）

1. 「我喝这个就感冒好了」——这属于哪一层证据？为何不能证明疗效？
2. 「量子玄学能治病」——是科学还是伪科学？判断依据？
3. 「研究说吃X活得久」——如何判断是否把相关当因果？
4. 一个「被主流打压的发明」故事——逐条检验其可证伪性。
5. 给出一个「阴谋论」常见论证，并用「举证责任 + 不可证伪 + 奥卡姆」反击。

---

## 8. 自查清单

- [ ] 我能用可证伪性检验一个主张吗？
- [ ] 我能把证据放到「证据金字塔」中判断强度吗？
- [ ] 我会用「相关≠因果」和「混杂变量」审因果吗？
- [ ] 我能识破伪科学的常见套路并给出机制质疑吗？
- [ ] 面对阴谋论，我能把举证责任还给主张方并指出其不可证伪吗？
