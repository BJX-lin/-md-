# 01 · 形式逻辑基础（Formal Logic）

> 形式逻辑研究「推理的结构」本身，与内容真假无关。它是整个论证体系的骨架：
> 只要结构对（有效），内容再荒谬，也「逻辑上成立」；而内容为真但结构断裂，则「不合逻辑」。

---

## 1. 逻辑学的三个层次

| 层次 | 研究对象 | 例子 |
|---|---|---|
| 语形学（Syntax） | 表达式该如何正确构成 | 「P → Q」是否是一个合法公式 |
| 语义学（Semantics） | 符号在什么条件下为真 | P→Q 在 P 真 Q 假时取假值 |
| 语用学（Pragmatics） | 在实际语境中如何被使用 | 说「你不抽烟了吗」的预设 |

- **命题（proposition）**：可判定真假的陈述句。如「今天下雨」。不是所有句子都是命题（疑问句、祈使句不是）。
- **原子命题**：不再拆分的最小命题，记作 P、Q、R。
- **复合命题**：由联结词把原子命题组合而成。

---

## 2. 命题联结词（Propositional Connectives）

### 2.1 五大基本联结词

| 名称 | 符号 | 中文读法 | 为真的条件 | 天然语言对应 |
|---|---|---|---|---|
| 否定 | ¬P | 非P | P 为假 | 不、并非 |
| 合取 | P ∧ Q | P且Q | 二者都真 | 并且、同时 |
| 析取 | P ∨ Q | P或Q | 至少一真 | 或者、或 |
| 蕴涵 | P → Q | 若P则Q | 仅当 P 真 Q 假时为假 | 如果……那么…… |
| 双条件 | P ↔ Q | P当且仅当Q | P、Q 真值相同 | 当且仅当 |

> **⚠️ 最容易被误解的是「实质蕴涵」（material implication）**：
> 「如果 P 那么 Q」只在「P 为真且 Q 为假」时为假，其余三种情况（P 假 Q 假、P 假 Q 真、P 真 Q 真）都判为真。
> 例如「如果你考满分，我就给你买奶茶」，当你没考满分时，这句话逻辑上被判定为「真」（因为前提为假时，整个条件句是「空洞真」）。
> **推论**：从一个假前提出发，可以推出任意结论（`explosion` / 爆炸原则：P ∧ ¬P ⊢ Q）。这是「归谬法」的底层逻辑。

### 2.2 真值表（Truth Table）快速参考

```
P  Q   ¬P    P∧Q   P∨Q   P→Q   P↔Q
T  T    F      T     T     T      T
T  F    F      F     T     F      F
F  T    T      F     T     T      F
F  F    T      F     F     T      T
```

### 2.3 常用等值式（逻辑恒等式）

- 双重否定：¬¬P ⟺ P
- 德摩根律：¬(P∧Q) ⟺ ¬P∨¬Q ；¬(P∨Q) ⟺ ¬P∧¬Q
- 交换律：P∧Q ⟺ Q∧P ；P∨Q ⟺ Q∨P
- 结合律：(P∧Q)∧R ⟺ P∧(Q∧R) ；（P∨Q）∨R ⟺ P∨（Q∨R）
- 分配律：P∧(Q∨R) ⟺ (P∧Q)∨(P∧R) ；P∨(Q∧R) ⟺ (P∨Q)∧(P∨R)
- 蕴含改写：P→Q ⟺ ¬P∨Q ；P→Q ⟺ ¬Q→¬P（**逆否**，等价）；但 Q→P（**逆命题**）与 ¬P→¬Q（**否命题**）**不**与 P→Q 等价。
- 吸收律：P∧(P∨Q) ⟺ P ；P∨(P∧Q) ⟺ P
- 排中律：P∨¬P（恒真，二值逻辑）
- 矛盾律：¬(P∧¬P)（恒假）

> **⚠️ 条件句四个「变体」——辩论中出错率最高的地方**：
> - 原命题：P → Q
> - 逆否命题：¬Q → ¬P（**等价于原命题** ✔）
> - 逆命题：Q → P（✘ 不等价）
> - 否命题：¬P → ¬Q（✘ 不等价）
> 例：「如果下雨，地面湿」(P→Q)。逆否「地面不湿 → 没下雨」成立；但逆命题「地面湿 → 下雨」（洒水也可能湿）不成立。

## 3. 谓词逻辑（Predicate Logic / 一阶逻辑）

当需要表达「所有」「有些」，命题逻辑不够用，引入**量词 + 谓词**。

- **谓词**：表示对象性质的词，如 `R(x)` = x 是红色的。
- **量词**：
  - 全称量词 ∀：∀x (R(x))＝所有 x 都是红的。
  - 存在量词 ∃：∃x (R(x))＝存在至少一个 x 是红的。

### 3.1 量词否定（否定移动规则）

- ¬∀x P(x) ⟺ ∃x ¬P(x)（「并非所有…」＝「至少有一个不…」）
- ¬∃x P(x) ⟺ ∀x ¬P(x)（「没有一个…」＝「所有都不…」）

> 例：
> 「不是所有人都支持该法案」 ⟺ 「至少有人不支持该法案」。
> 「不存在免费午餐」 ⟺ 「所有午餐都不免费」。

### 3.2 常见三段论量化形式（传统逻辑）

| 形式 | 中文 | 全称/特称与肯定/否定 |
|---|---|---|
| 全称肯定 A | 所有 S 都是 P | ∀x(Sx→Px) |
| 全称否定 E | 所有 S 都不是 P | ∀x(Sx→¬Px) |
| 特称肯定 I | 有些 S 是 P | ∃x(Sx∧Px) |
| 特称否定 O | 有些 S 不是 P | ∃x(Sx∧¬Px) |

> **方阵（Square of Opposition）关键规则**：
> - A 与 O 是矛盾关系（不能同真也不能同假）：「所有S是P」为真 ⟺「有些S不是P」为假。
> - E 与 I 是矛盾关系。
> - A 真 ⟹ I 真（若假设有对象存在）。若域为空，则 A 真而 I 假（现代逻辑的「存在预设」问题，辩论中常见陷阱）。

## 4. 经典推理规则（Inference Rules）——「逻辑直尺」

### 4.1 基本有效推理式（必须背熟）

| 名称 | 形式 | 说明 |
|---|---|---|
| 肯定前件 Modus Ponens | P→Q, P ⊢ Q | 若P则Q，P真，故Q真 |
| 否定后件 Modus Tollens | P→Q, ¬Q ⊢ ¬P | 若P则Q，Q假，故P假 |
| 假言三段论 | P→Q, Q→R ⊢ P→R | 传递 |
| 选言三段论 | P∨Q, ¬P ⊢ Q | 排除一个，剩另一个 |
| 合取消去 | P∧Q ⊢ P | 且关系中可取任一 |
| 合取引入 | P, Q ⊢ P∧Q | |
| 构造性二难 | P→Q, R→Q, P∨R ⊢ Q | 无论哪条路都到同一结论 |
| 归谬法 Reductio ad Absurdum | (P→Q), (P→¬Q) ⊢ ¬P | 假设P推出矛盾，所以¬P |
| 双重否定引入/消去 | P ⊢ ¬¬P；¬¬P ⊢ P | |
| 逆否律 | P→Q ⊢ ¬Q→¬P | |

### 4.2 常见无效式（辩论中对方常偷用）

| 名称 | 错误形式 | 为什么错 |
|---|---|---|
| 肯定后件（Affirming the consequent） | P→Q, Q ⊢ P | Q 可由其他原因导致（洒水也湿） |
| 否定前件（Denying the antecedent） | P→Q, ¬P ⊢ ¬Q | P 不是导致 Q 的唯一条件 |
| 中项不周延（Undistributed middle） | 所有M是P，所有S是M ⟹ 所有S是P（错误在于中项使用不周延） | 详见三段论 |
| 由充足条件误推必要 | 把 P→Q 当成 Q→P | 因果方向颠倒 |

## 5. 三段论（Syllogism）

经典三段论由**大前提、小前提、结论**三句构成，包含三个项：**大项(结论谓词)、小项(结论主词)、中项(联结二者、不在结论出现)**。

```
例：
  所有 人 都会死        ← 大前提（中项「人」+ 大项「会死」）
  苏格拉底 是 人        ← 小前提（小项「苏格拉底」+ 中项「人」）
  所以 苏格拉底 会死    ← 结论（小项「苏格拉底」+ 大项「会死」）
```

### 5.1 三段论有效性三规则（简洁版）

1. **中项至少周延一次**（至少要覆盖其整个外延）。
2. **在前提中不周延的项，结论中不得周延**（「大项不当周延」「小项不当周延」是常错点）。
3. **两个否定前提推不出结论**；前提一否定则结论必否定；两个特称前提推不出结论。

> 快速判定「周延」（distribution）：
> - 全称A/全称E 的主项周延；全称E/特称O 的谓项周延。
> 即「周延」的是：全称的主项 + 否定的谓项。

### 5.2 常见三段论谬误

- **四词谬误（Equivocation）**：中项在两个前提中词义不同（「人是理性的；威尼斯人是…；所以…」的伪同构）。
- **中项不周延**：例「所有狗都吃草料；牛吃草料；所以牛是狗。」中项「吃草料」未周延。
- **大项不当周延**、**小项不当周延**：项在前提里没周延，结论里周延了。

## 6. 形式化证明：一整套「降维打击」的流水线

形式化（symbolize）可以暴露出自然语言的含糊，也便于验证结构。

**步骤**：
1. 找到所有原子命题，用 P,Q,R… 代表。
2. 用联结词把自然句翻译成公式。
3. 判断论证属于哪类结构；套用推理规则或真值表验证有效性。
4. 若无效：给出一个反例赋值（让前提真、结论假）。

### 6.1 反例法（检验有效性）举例

论证「P→Q, Q ⊢ P」（肯定后件）。检验有无赋值使前提真、结论假：
- 取 P=假, Q=真：P→Q = 假→真 = 真；Q=真；但结论 P=假。前提真而结论假 ⟹ **无效**。

### 6.2 自然演绎示例

证明：(P→Q) ∧ (Q→R) ⊢ (P→R)
```
1  (P→Q)          （合取消去）
2  (Q→R)          （合取消去）
3  P              （假设，为证明所需）
4  Q              （1,3 肯定前件）
5  R              （2,4 肯定前件）
6  P→R            （3-5 条件证明）
```

### 6.3 归谬法示例

证明：若 P→Q 且 P→¬Q，则 ¬P。
```
1  P→Q
2  P→¬Q
3  P              （假设）
4  Q              （1,3 肯定前件）
5  ¬Q             （2,3 肯定前件）
6  Q∧¬Q           （4,5 合取引入，矛盾）
7  ¬P             （3-6 归谬）
```

## 7. 逻辑形式在实战中的使用（辩论视角）

- **「还原结构」是第一步**：对方长篇大论，你只需问：它的前提是什么？它把哪个作为「若……则……」？
- **警惕「有效性不等于正确」**：结构完美的论证可能建立在假前提上。反驳的有效点常是「前提为假」，而非「不合逻辑」。
- **利用逆否**：将一个强主张转换成其逆否命题，有时逆否命题更容易证伪。
- **利用归谬**：把对方前提加以推广到荒谬结论（reductio），是瓦解论证的高效武器。
- **警惕量化陷阱**：「有些」到底是不是「存在」？「所有」的域如何界定？对方常在此含糊。
