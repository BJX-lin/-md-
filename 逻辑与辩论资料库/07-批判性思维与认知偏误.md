# 07 · 批判性思维与认知偏误（Critical Thinking & Cognitive Biases）

> 前几章讲「论证」与「对手」。本章讲「你自己」——为什么你会被说服、会犯错。
> 批判性思维 = 主动审查自己信念来源的能力；认知偏误 = 系统性的思维偏差。识破偏误，是抵御操纵和避免自我盲点的基础。

---

## 1. 批判性思维的定义

> 批判性思维（Critical Thinking）：以**证据、逻辑、系统性**为标准，主动检视**信念、推理、论证**是否成立的思维习惯。

四个核心子能力：

| 能力 | 说明 |
|---|---|
| 识别 | 找出断言、论点、论断及其背后的假设 |
| 评估 | 判断证据的相关性、可信度、充分性 |
| 推断 | 依据证据推出合理结论，并识别局限 |
| 更新 | 有新的好证据时愿意修正自己的信念（可证伪性） |

> 与辩论的联系：批判性思维让你**既当攻击者也当受审者**——审查对方，也审查自己。真正的强者能「自我证伪」。

---

## 2. 批判性思维的具体检查步骤（对一个主张逐一过）

1. **这个主张可真/可假吗？**（若无法证伪，谨慎对待。）
2. **支持它的证据是什么？** 来自哪、多可信、有多相关。
3. **反对它的证据/观点是什么？** 我主动找了吗？
4. **结论的强度是否与证据匹配？**（「少量证据 → 强断言」就危险。）
5. **是否存在替代解释？** 尤其是「最想相信的那个」。
6. **如果我是对立面，我会怎么攻击它？**（为自己做 Steinman 式压力测试。）

---

## 3. 苏格拉底式提问（Socratic Questioning）——拆信念的利器

一种层层追问、逼出论证根基的对话方式。六大类问题：

| 类别 | 问题示例 |
|---|---|
| 澄清概念 | 「你所说的‘公平’具体指什么？」 |
| 追问假设 | 「你默认什么是真的？可证明吗？」 |
| 追来源与证据 | 「你的依据是什么？可靠吗？」 |
| 探索视角 | 「站在对方/第三方的角度看，会怎样？」 |
| 追问含义与后果 | 「如果同意，会推出什么后果？」 |
| 追问反例 | 「什么情况下会不成立？」 |

> 用法：与对手/大模型对弈时，用这些问题把对方拉到「必须给出证据」的位置；对自己，则用来审查自己的立场。

## 4. 认知偏误（Cognitive Biases）——系统性思维陷阱

> 这些是人类大脑的「默认设置」，不分智商。识别它们，是抗操纵的核心。按类别梳理。

### 4.1 与「证实」有关的偏误（最需警惕）

| 偏误 | 说明 | 例子 |
|---|---|---|
| 证实偏误（Confirmation Bias） | 只寻找支持已有信念的证据，忽略反证 | 只关注支持「XX有效」的新闻 |
| 动机性推理（Motivated Reasoning） | 先有结论，再合理化 | 「我好希望这是真的，所以相信」 |
| 预设答案（Cherry Picking） | 挑选有利证据 | 只展示支持自己的数据 |
| 丹宁-克鲁格效应（Dunning-Kruger） | 能力越弱越高估自己 | 新手最自信 |
| 后见之明偏误（Hindsight Bias） | 事后觉得「我早料到」 | 「我早说过会这样」 |

### 4.2 与「证据与因果」有关的偏误

| 偏误 | 说明 |
|---|---|
| 基率忽略（Base Rate Neglect） | 忽略基础概率，只看局部特征（见第 3 章） |
| 因果错觉（Illusion of Causality） | 把巧合/相关当因果 |
| 叙事谬误（Narrative Fallacy） | 偏爱能讲成故事的复杂事实，忽略杂乱证据 |
| 赌徒谬误 / 热手谬误 | 错误假定独立性 |
| 可得性启发（Availability Heuristic） | 越容易想起的越觉得常见（因新闻/情绪而高估风险） |
| 锚定效应（Anchoring） | 受最先给出的数字影响 |

### 4.3 与「自我与身份」有关的偏误

| 偏误 | 说明 |
|---|---|
| 光环效应（Halo Effect） | 因喜欢某一点而整体美化 |
| 刻板印象（Stereotype） | 用群体标签代替个体评估 |
| 自我服务偏误（Self-serving Bias） | 成功归己、失败归环境 |
| 虚假共识（False Consensus） | 以为多数人跟我一样想 |
| 自适应偏好（Sour Grapes） | 「得不到的就贬低它」 |
| 沉没成本（Sunk Cost） | 因已投入而继续 |

### 4.4 与「群体与权威」有关的偏误

| 偏误 | 说明 |
|---|---|
| 从众（Bandwagon） | 倾向跟随多数 |
| 权威偏误（Authority Bias） | 高估权威观点，忽视其可能错误 |
| 群体思维（Groupthink） | 集体中为和谐而放弃批判 |
| 社会认同（Social Proof） | 不确定性时参考他人 |
| 服从权威（Milgram） | 在权威面前易放弃独立判断 |

## 5. 「自我证伪」训练——批判性思维的高级练习

对抗自己的偏误，最有效的做法是**主动寻找反对自己的证据**：

- **红队思考（Red Teaming）**：专门指派自己「扮演敌人」，找出自己论证最脆弱的点。
- **逆向假设**：「如果我这个观点是错的，什么会支持它？」
- **Steelman 自己的对立面**：先把对手最强的版本写出来，再回应。
- **预设可证伪**：明确「如果出现什么证据，我会改变看法？」若无此预设，则信念可能不具可证伪性。

> 一句话：**真正的批判性思维，是对自己的观点也保持怀疑。**

---

## 6. 风险/概率思维（数学化地看待证据）

- **区分「可能性」与「概率」**：可能 ≠ 很可能。
- **把「很可能」量化**：是 51%? 60%? 90%? 模糊概率更容易被操纵。
- **更新信念**：贝叶斯思维——新证据应让你「按比例」调整，而非全盘倒戈或完全无视。
- **警惕「罕见但戏剧化」**：可得性更关注戏剧性的罕见事件，而忽略高频率的普通风险。

---

## 7. 对照表：偏误 → 反驳/自护方法

| 被操纵的偏误 | 防御/对冲 |
|---|---|
| 证实偏误 | 主动找反证，强制自己列两条反对理由 |
| 可得性/情绪 | 校准真实概率（用数据，不用新闻热度） |
| 权威 | 检查专家相关性与利益冲突 |
| 社会认同/从众 | 问「多数是否相关？」 |
| 锚定 | 先独立评估，再报价 |
| 沉没成本 | 只按未来收益决策 |
| 光环/喜好 | 把「喜欢」与「证据」分开 |
| 基率忽略 | 用贝叶斯计算真实概率 |
| 幸存者/叙事 | 追问「被我忽略的分母/反例在哪」 |
