# 09 · 术语中英对照表（Bilingual Glossary）

> 汇总本书出现的核心术语，按主题分组，中英对照，便于跨语言检索与喂给大模型时统一术语。
> 阅读或对弈时可直接检索，避免一词多义的混淆。

---

## A. 逻辑学与论证结构（Logic & Argumentation）

| 中文 | 英文 | 简要说明 |
|---|---|---|
| 论证 | Argument | 由前提支撑结论的一组陈述 |
| 前提/理由 | Premise / Grounds | 支撑结论的陈述 |
| 结论/主张 | Conclusion / Claim | 论证想要证明/接受的陈述 |
| 论证联结/推理保证 | Warrant | 把前提连接到结论的规则 |
| 支撑 | Backing | 对保证的进一步辩护 |
| 限定词 | Qualifier | 结论的语气强度（必然/很可能/通常） |
| 反驳 | Rebuttal | 例外、反对意见 |
| 演绎论证 | Deductive Argument | 前提真则结论必真 |
| 归纳论证 | Inductive Argument | 前提真则结论很可能真 |
| 溯因论证 | Abductive Argument | 由现象推最佳解释 |
| 有效性 | Validity | 结构上前提真则结论必真 |
| 可靠性 | Soundness | 有效 + 前提皆真 |
| 证明责任 | Burden of Proof | 谁主张谁举证 |
| 论证方案 | Argumentation Scheme | 常见论证模式（从权威/类比/因果等） |
| 图尔敏模型 | Toulmin Model | 六要素论证分析模型 |

## B. 命题与推理（Proposition & Inference）

| 中文 | 英文 | 说明 |
|---|---|---|
| 命题 | Proposition | 可判真假的陈述句 |
| 原子命题 | Atomic Proposition | 不可再分的命题 |
| 合取 | Conjunction | P 且 Q（∧） |
| 析取 | Disjunction | P 或 Q（∨） |
| 否定 | Negation | 非 P（¬） |
| 蕴涵 | Implication / Material Implication | 若 P 则 Q（→） |
| 双条件 | Biconditional | P 当且仅当 Q（↔） |
| 真值表 | Truth Table | 罗列所有真值组合的判定表 |
| 逻辑等值 | Logical Equivalence | 两式真值表相同（⟺） |
| 有效推理式 | Valid Inference | 保真的推理形式 |
| 肯定前件 | Modus Ponens | P→Q, P ⊢ Q |
| 否定后件 | Modus Tollens | P→Q, ¬Q ⊢ ¬P |
| 归谬法 | Reductio ad Absurdum | 假设P推出矛盾故¬P |
| 三段论 | Syllogism | 大前提+小前提→结论 |
| 中项 | Middle Term | 联结大项小项、不在结论出现的项 |
| 周延 | Distribution | 项是否覆盖其全部外延 |
| 全称量词 | Universal Quantifier | ∀（所有） |
| 存在量词 | Existential Quantifier | ∃（有些/存在） |

| 以偏概全 | Hasty Generalization | 少量样本推全体 |
| 轻率类比 | Weak / False Analogy | 表面相似即类比 |
| 假因果 | Post Hoc Ergo Propter Hoc | 先后即因果 |
| 相关≠因果 | Correlation ≠ Causation | 相关不代表因果 |

| 基率忽略 | Base Rate Neglect | 忽略基础概率 |

| 赌徒谬误 | Gambler's Fallacy | 错误假设独立性 |
| 沉没成本 | Sunk Cost | 因已投入而继续 |
