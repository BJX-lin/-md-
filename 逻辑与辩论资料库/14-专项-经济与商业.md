# 14 · 专项领域：经济与商业（Economics & Business）

> 经济与商业论证的特点：**依赖数据与统计、充满模型假设、常有利益立场、且是「预测」主导**。
> 目标：掌握「相关≠因果」「机会成本」「激励」等经济思维，识破经济论证中的数据操纵与利益偏向。

---

## 1. 经济思维的核心概念（论证的基底）

| 概念 | 含义 | 攻防价值 |
|---|---|---|
| 机会成本 Opportunity Cost | 选A放弃的最大价值 | 「免费」并不免费；用于戳穿「零成本」 |
| 边际分析与激励 Marginal/Incentive | 人在边界处对激励的反应 | 政策有效性取决于激励是否对齐 |
| 均衡与市场 | 供求如何决定价格/数量 | 「贵=缺」「降价=需求弱」未必 |
| 外部性 Externality | 行为影响第三方 | 「市场失灵」与政府干预的理由 |
| 供需的两面 | 价格影响数量、数量影响价格 | 警惕单向因果断言 |
| 效率 vs 公平 | 增长 vs 分配 | 政策在两者间权衡 |

---

## 2. 经济论证的常见模式与弱点

| 模式 | 结构 | 击破点 |
|---|---|---|
| 从 GDP/增长 | X 促进增长，故应做 | 增长是否分配公平/可持续；口径是否被操纵 |
| 从「市场化/自由」 | 市场自会解决 | 市场失灵（外部性、公共品、信息不对称） |
| 从「政府干预」 | 政府该管 | 政府失灵（寻租、低效、被俘虏） |
| 从「省钱/降本」 | 这能省钱 | 是否忽略隐性/长期成本；机会成本多少 |
| 从「就业」 | X 创造就业 | 是否净增就业、代价/质量如何 |
| 从「数据/统计」 | 数字证明了… | 口径、基期、对比基数、相关≠因果 |

---

## 3. 统计/数据操纵的常见手法（经济辩论最重要的武器）

| 手法 | 说明 | 反击 |
|---|---|---|
| 精选基期 | 选一个对己有利的基准年 | 换多个基期看趋势是否稳健 |
| 选择性删减 | 只报一段/一部分 | 补全时间序列与全样本 |
| 断章数字 | 只看总量忽略人均/增速 | 同时看绝对量与相对量 |
| 相关说成因果 | 用趋势线暗示因果 | 要求机制 + 排除混淆 |
| 平均数陷阱 | 用均值掩盖分布（中位数/众数） | 看分布、中位数、基尼等 |
| 样本偏差 | 只统计部分人群/时期 | 追问样本代表性与选择机制 |
| 预测谬误 | 把「预测」当「既定事实」 | 要求预测方法与置信区间 |

## 4. 经济论证博弈的提示词模板（对 AI）

```
【经济主张】<粘贴一条「X 会导致/解决 Y 经济问题」/请给出经济分析/>
请作为经济学家：
1) 这个主张是把【相关当因果】吗？有无混杂变量？
2) 它考虑了【机会成本】和【边际/激励】吗？
3) 数据是【已实现】还是【预测】？口径/基期是否清晰？
4) 它偏向【效率】还是【公平】？可能的外部性是什么？
5) 用【供给-需求/边际】框架重新检验，结论还成立吗？
6) 给出一条最可能被反对的点，并写一个【针对性反驳】。
```

## 5. 商业/商务论证（谈判、营销、投资说辞）专项

### 5.1 营销/销售说辞的常见操纵
- **稀缺/限时**：「最后机会」→ 问是否真稀缺、制造紧张。
- **从众/社会认同**：「买的人最多」→ 问是否相关、是否买账。
- **锚定**：先给高价再给「折扣价」→ 别被锚定，回看市场基准价。
- **诉诸权威/明星**：「专家/名人推荐」→ 是否利益相关、是否该领域权威。
- **虚假对比**：与包装成「更贵」的假参照对比 → 用客观比价。

### 5.2 投资/商业预测论证
- 任何「确定性回报」：警惕「风险收益不对称」的承诺，高收益必高风险。
- 「故事性叙事」：叙事好 ≠ 商业模式成立，看现金流与护城河。
- 用「最坏情况」压力测试，而非只用乐观情景。

## 6. 练习题库（经济议题）

1. 「进口多了所以失业多」——用「相关≠因果 + 其他因素」检验。
2. 「这项补贴能省钱」——找出被忽略的机会成本与隐性/长期成本。
3. 一个「数据显示好」的营销——用「统计操纵」手法逐一审。
4. 「政府该管还是该放」——分别列出市场失灵与政府失灵的依据。
5. 用「激励」视角分析：为什么某个政策可能无效？
