# 17 · 专项领域：媒体、信息与事实核查（Media, Information & Fact-checking）

> 信息时代最大的敌人是「失真」与「操纵」。这一章教你**评估信息来源、识别假新闻/带偏叙事、进行事实核查**。
> 目标：建立一套「不信单一来源、不回未核实、不传播已证伪」的可执行流程。

---

## 1. 信息来源的可信度分级

| 级别 | 类别 | 说明 |
|---|---|---|
| 高 | 官方/学术/数据库，有同行评审 | 权威、可核验，但仍需看领域相关 |
| 中 | 主流平衡报道、多方来源交叉 | 有用的二手来源，需交叉验证 |
| 弱 | 自媒体、来源不明、情绪化 | 单凭某一人/社媒不可靠 |
| 很弱 | 匿名、无来源、耸动标题 | 当作观点/情绪，不作事实 |

> **博弈要点**：判定一个信息，先问「这是第一手来源吗？能被独立验证吗？」「有多少独立来源印证？」「来源方有无立场/利益？」

---

## 2. 假新闻与带偏叙事的常见手法

| 手法 | 说明 | 识别信号 |
|---|---|---|
| 断章取义 | 截取片段曲解原意 | 上下文缺失、句意反转 |
| 标题党（clickbait） | 标题与内容不符 | 标题情绪化、无依据 |
| 移花接木 | 旧图/旧事套新标题 | 时间、地点对不上 |
| 伪造源头 | 编造「权威」出处 | 无法找到原始出处 |
| 合成/篡改图片 | 用AI/PS造图 | 细节失真、可反向检索 |
| 精心截取数字 | 挑有利数据 | 看全样本/口径 |
| 双标/选择报道 | 只报一边 | 找对立报道对比 |
| 以偏概全 | 个案代表整体 | 样本量、代表性 |

---

## 3. 事实核查的标准流程（六步）

1. **核对来源**：信息最初来自哪里？是第一手吗？
2. **反向检索**：用关键词、图片搜索找原始出处，看是否真实。
3. **交叉验证**：找≥2个独立可靠来源。
4. **核对关键细节**：数字、日期、人名、地点、引语是否准确。
5. **考察语境**：是否被断章取义、缺上下文。
6. **评估争议方**：这是「已证事实」「多方共识」，还是「尚在争议/某人观点」？

> **通用原则**：越是震撼、越与你立场一致的内容，越要加倍小心（正是它们容易触发潜意识接受）。

---

## 4. 信息环境中的认知陷阱（回顾第 7 章在媒体中的应用）

- **回音室（Echo Chamber）**：只接触与自己观点一致的信息 → 需主动接触反方。
- **信息茧房（Filter Bubble）**：算法推荐强化偏误 → 主动换源、跨立场。
- **动机性推理**：因为想信所以信 → 强制自己先看反证。
- **可得性启发**：新闻渲染让人高估罕见风险 → 校准真实概率。

---

## 5. 事实核查博弈的提示词模板（对 AI）

```
【待核实声明】<粘贴一条「某数据/某事实/某事件」的表述/请核查/>
请作为事实核查员：
1) 原始来源是什么？能否追溯到一手资料？
2) 我能给出【独立交叉验证】吗？有多可靠？
3) 核对【关键细节】（数字/日期/人名/引语），有无出入？
4) 是否被【断章取义/移花接木/标题党】？
5) 结论：【已证实/已证伪/未经证实/尚在争议/缺乏证据】中的哪类，并说明理由与置信度。
```

## 6. 练习题库（媒体信息议题）

1. 给一段「标题很劲爆」的新闻，用「六步核查」审其可信度。
2. 一个「AI 生成的假图」——列哪些细节可以反证其为假？
3. 「权威媒体都说 X」——该信息属于哪些层来源？如何交叉验证？
4. 识别一段「断章取义」的引语：如何找回完整语境？
5. 设计一个「如何避免回音室」的个人流程。
