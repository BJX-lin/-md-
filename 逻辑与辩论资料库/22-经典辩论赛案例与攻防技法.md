# 22 · 经典辩论赛案例与攻防技法（Classic Debate Cases & Techniques）

> 本章引用（并改写）华语辩论经典赛事中的名场面与攻防技法，用于自学与喂给离线博弈游戏。
> 每条含：赛事出处 → 辩题 → 双方立论要点 → 胜负或公认结论 → 可复用的经典技法。

## 导读：为什么经典辩论赛是最好的教材

经典辩论赛展示的不是“谁对”，而是**如何把一场交锋的方法论演出来**。可提炼出的「可复用技战法」：

- **定义战**：抢先给核心词下定义，把战场拉到对己有利处。
- **概念切割**：把一个词的“整体”与“其中一部分可取”切开，避免被“有一点好=整体好”拖垮。
- **反例打击**：用一个满足对方条件却显然不成立的例子，一击致命。
- **归谬类比**：把对方前提推到一个荒谬的同类情形（如“追求无限→万恶，那健康/爱情也万恶？”）。
- **偷换论题的反击**：指出对方证明的是“努力”，你要的是“有效”。
- **“你没反驳就赢”的反击**：对方说“你没反驳我，所以我说得对”，用“那要评委干嘛”幽默拆穿。
- **价值层升华**：把“行为约束”拔高到“内心认同”，抢占价值高地。

## 案例 1 · 人性本善 / 人性本恶（1993 国际大专辩论赛决赛 · 台大 vs 复旦）

- **正方（本善）要点**：孟子“见孺子将入井皆有恻隐之心”；康德“人皆有理性（良心）”；佛家“放下屠刀立地成佛”。→ 有善端才有善行。
- **反方（本恶）要点**：荀子、霍布斯——若无绝对权威监督，人不会自愿守道德；善行来自“社会属性/教化”；“本恶”不等于后天皆恶，而正因本恶才需教育与道德。
- **公认**：无定论。真正的金句是反方把对方拉进“本性与后天表现”之辨：“人性本善，为何会有恶果？既性本善，教化何用？”
- **可复用技法**：【区分本性与现象】用“那是后天教化/社会属性，不是本善”来挡住“人有利他行为”的攻击。**这是你防守“因为有人做好事所以人性本善”的利器。**

## 案例 2 · 钱是万恶之源 / 钱不是万恶之源（2001 国际大专辩论赛决赛）

- **正方（是）要点**：金钱等效用的无限 vs 个人占有的有限，激起无穷贪欲；金钱从“手段”异化为“目的”，人从“主人”沦为“奴隶”；《辞海》“万”意为“极多”，只需证明“种类繁复、数量极多的罪恶”。
- **反方（不是）要点**：“万恶之源”本义是“一切恶的根源”，钱无法涵盖全部恶；四大类恶（信念极端／价值非理性／情欲／伦理滥用）多数与钱无关；人具自由意志需负责，关键在“人”而非“钱”；钱能结善果（奉养父母、慈善、建设国家）。
- **公认**：经典拉锯，几乎成华语辩论教科书。反方的**定义战**（把“万”解释成“一切”，加重对方举证）与**归谬类比**（“追求无限→万恶，那道德、健康、爱情也无限，岂不都是万恶之源？”）最出彩。
- **可复用技法**：
  - 【定义战】把“万”往“一切”方向解释，逼对方无法穷尽。
  - 【归谬类比】“你追求 X 也是无限的，难道 X 也万恶？”——用对方逻辑反杀。

## 案例 3 · 以成败论英雄是可取的 / 不可取的（2001 国际大专辩论赛复赛）

- **正方（可取）要点**：把“以成败论英雄”界定为“一种鼓励追求成功的价值观”（非唯一标准），只需证明“有可取之处”即可。
- **反方（不可取）要点**：岳飞、文天祥失败了却仍是英雄；整体“可取”不代表局部“可取”；把“成功”随意界定——“说你成你就成，不成也成”。
- **公认**：正方靠“价值观定位 + 只需证明可取”防守，反方靠“失败的英雄”反例与“有一点可取≠整体可取”破局。
- **可复用技法**：【敲例反杀】反复用“失败却仍是英雄”这类反例，要么逼对方承认，要么耗掉其战场。

## 案例 4 · 温饱是谈道德的必要条件 / 不是（1993 初赛 · 剑桥 vs 复旦）

- **正方（是）要点**：温饱=生存基础，生存是谈道德的前提。
- **反方（不是）要点**：用历史实例反驳“温饱=生存”的偷换；类比反打“基础论”——**“人吃饭是为了活着，但活着就是为了吃饭吗？”**；贫而志不移、饿而不苟且者自古不乏。
- **公认**：反方胜。关键是戳破正方把“温饱”偷换成“生存”，再用“吃饭=活着”类比拆“生存=道德基础”。
- **可复用技法**：【类比反拆】对方用“A 是 B 的基础”，找一个“A 是 B 的所需、但绝非 B 的意义”的类比（吃饭 vs 活着），一举拆穿必备/充分混淆。

## 案例 5 · 真理越辩越明 / 不会越辩越明（1997 决赛 · 首都师大 vs 马来亚）

- **正方（会）要点**：有辩的存在，真理越辩越明；引用科技史、波普尔“猜想反驳”。
- **反方（不会）要点**：辩不必然带来真理——白马黑马辩不出真伪；“复制羊不是羊、试管婴儿不是儿？”，狡辩/诡辩也算辩；现实有利益、语言、情绪限制；真理常靠检验（曼德尔用豆苗实验而非辩论，苹果酸甜是尝不是辩）。
- **公认**：反方靠“一句反例就够”（充分条件只需一例推翻）与“辩中大量非真理行为”建立优势。
- **可复用技法**：【充分条件击破】对方把“辩”当作“真理的充分条件”，你只需一个“有辩却没得出真理”的反例（白马黑马、苹果酸甜）即可瓦解。**这个“只需一个反例就打倒充分条件”的思路，可用于任何把某物当充要条件的论证。**

## 案例 6 · 网络使人更亲近 / 更疏远（1999 初赛 · 马来亚 vs 澳门大学）

- **正方（亲近）要点**：网络降低沟通成本，连接更多人；“亲近”=连接更广、交流更多。
- **反方（疏远）要点**：连接多是“表面”，深层信任与陪伴在减少；“点赞之交”不亲近；亲近是情感深度而非人数。
- **公认**：关键在于“亲近”的定义——广度还是深度。反方靠定义战把“亲近”界定为“深度/信任”来破解正方的“广度/连接多”。
- **可复用技法**：【定义战】把一个中性的词（亲近）往“深度/信任/质”方向解释，对手若只证明“量/广”，就落入了你设的陷阱。

## 案例 7 · 社会秩序的维系主要靠法律 / 道德（1995 半决赛 · 南京大学 vs 香港中文）

- **正方（法律）要点**：法律以强制力为后盾，明确、稳定、可执行；道德靠自觉、不确定；底线秩序须“硬约束”兜底。
- **反方（道德）要点**：法律能规范行为无法规范内心；道德“提前预防”先于法律“事后惩罚”；法律本身需道德支持才能运转；治本在人心。
- **公认**：价值辩，比的是“底线秩序”与“深层稳定”何者更根本。
- **可复用技法**：【价值层升华】把“维系”从“行为约束”拔高到“内心认同”，抢占价值高地——这是价值类辩题通用的升维打法。

## 汇总 · 通用攻防套路（喂给离线 AI 也适用）

| 套路 | 一句话 | 适用场景 |
|---|---|---|
| 定义战 | 先给“X”下定义，把战场拉到对己有利处 | 关键词有歧义时 |
| 概念切割 | “X 整体可取”≠“X 每个局部可取” | 对方说“有一个好处=整体好” |
| 反例打击 | 一个满足条件却显然不成立的例子即可 | 对方用“充分条件/必然”时 |
| 归谬类比 | 把对方前提推到一个荒谬的同类情形 | 对方逻辑有普遍性漏洞时 |
| 基础论反拆 | “A 是 B 的所需，但绝非 B 的意义” | 对方说“A 是 B 的基础/条件” |
| 偷换概念反击 | “你证明的是努力，我要的是有效” | 对方转移/偷换论题 |
| “你没反驳=你输了”反击 | “不然要评委干嘛” | 对方拿“你没反驳”当胜利 |
| 价值层升华 | 从“行为约束”升到“内心认同” | 价值类 / 规范类辩题 |

## 与离线博弈游戏的关系

这些案例与技法已写入游戏（`godot_logic_game/scripts/KnowledgeBase.gd` 的 `DEBATE_CASES` 与 `DEBATE_MOVES`）。当游戏掷出这些经典辩题时，会：

1. 在题面附上**典出**（哪一年哪场）与**经典技战法**。
2. 你发言后，AI 会**引一句该案例双方立场的核心要点**逼你回应（“经典视角：……你如何回应这一面？”）。
3. 中高难度下，AI 会用**经典辩手句式**（定义战 / 归谬类比 / 反例打击 / 偷换论题反击）来接招，听起来更像老辩手。
