# 逻辑辩论文字游戏（Godot 4 · 手机端 · 纯离线 · 聊天气泡界面）

一个**完全离线、不联网、不接任何云端 AI** 的文字博弈游戏。用户输入自己的观点/论证，一个“离线 AI”（本地规则引擎）用逻辑谬误与论证结构来“杠”你。界面是**类似聊天气泡的风格**，简洁清爽。

## 它是怎么“离线 AI”的

它**不是**真正的大模型——因为你要完全不接 AI、不联网。所以这里用的是**本地规则引擎**：

- `KnowledgeBase.gd` 相当于“大脑”，存放了《逻辑与辩论资料库》里的**20+ 种谬误规则**、苏格拉底式追问、归谬/通用攻击模板、辩题库、**真实争议议题知识库**（含各议题的立场锚点/核心冲突/事实弹药）与结算语。
- `DebateEngine.gd` 负责“理解”：用关键词 + 正则**侦测**你输入里命中哪种逻辑谬误，命中就给出**「识别 → 拆解 → 反问 → 归谬」**四连击；未命中则切换为**苏格拉底追问 / 通用拆解 / 归谬**。
- 带**计分、回合、辩题、结算判定**系统。

所以你“抛出一个观点”，它“用逻辑漏洞来杠你”。这套数据完全取自项目根目录的 `逻辑与辩论资料库/`。

## 功能一览

| 功能 | 说明 |
|---|---|
| 🎨 聊天气泡界面 | 玩家气泡靠右（绿）、AI 气泡靠左（深灰），含头像、昵称、时间戳；自动滚到底 |
| 🧠 20+ 种谬误识别 | 诉诸大众/权威、假两难、人身攻击（含处境）、滑坡、诉诸情感/无知/传统/自然/后果、红鲱鱼、偷换论题、循环论证、合成/分解、虚假类比、假因果、复杂问句、幸存者偏差、完美主义、中间立场等 |
| 🎯 随机辩题 | AI 主动抛出一个辩题（从辩题库随机抽），点「换辩题」即可重抽；其中 8+ 个是**真实争议议题**（死刑/安乐死/UBI/AI意识/基因编辑/加密货币/人脸识别等） |
| 🏁 回合与胜负结算 | 顶部显示双方计分条 + 回合数；回合结束自动弹「结算面板」，给出 命中/讲理/胜负判定 |

| 🔄 重开 | 清空重来 |

## 怎么运行

### 桌面预览（最快）
1. 用 **Godot 4.7.2 stable** 打开本文件夹（`godot_logic_game/project.godot`）。
2. 点 ▶ 运行即可在窗口中玩。

### 手机端（Android）
1. Godot 4.7.2 → 菜单 → 安装 **Android 构建模板（Build Template）**（首次）。
2. `项目 → 导出 → 添加 → Android`。
3. 配置 **Keystore / 签名 / 包名**（首次建一个 debug 密钥）。
4. 点「导出项目」得 `.apk`，安装到手机扫码可用；输入框会自动唤起软键盘。

### 手机端（iOS）
- 需 macOS + Xcode，经 Godot 导出后再打包。逻辑完全一致。

> 真机运行时**可完全断网**：整个游戏不发起任何网络请求、不调用任何外部 AI——所有“反驳”都来自本地的 `KnowledgeBase.gd`。

## 接招逻辑

- 你说的话 → 引擎先扫谬误 → 有就“命中”，给你四连击（识别/拆解/反问/归谬）。
- 你说得像在讲理（含“证据 / 因为 / 所以 / 反例 / 比如 / 假设…”）→ 引擎会夸你并给玩家加分。
- 你提问 → 苏格拉底式追问。
- 其余 → 通用拆解 / 归谬。

## 怎么拓展（把《资料库》更多内容加进去）

想让它“懂得更多”，**只改 `scripts/KnowledgeBase.gd`、不改引擎**：

- 在 `FALLACIES` 数组加一条 `{ "name", "en", "signals", "regex", "explain", "probe", "reductio" }`，即可多识别一种谬误。
- 在 `SOCRATIC / ATTACKS / REDUCTIO / PRAISE` 里加句子，让接招更丰富。
- 在 `TOPICS` 里加 `{ "topic", "ask" }`，增加更多辩题。
- 想接入真实本地 LLM（如 Ollama/llama.cpp），把 `DebateEngine.respond()` 换成调用本地推理即可——但那属于另一个“接 AI”的方向。
