# 逻辑辩论文字游戏（Godot 4 · 手机端 · 纯离线）

一个**完全离线、不联网、不接任何云端 AI** 的文字博弈游戏。用户输入自己的观点/论证，一个“离线 AI”（本地规则引擎）用逻辑谬误与论证结构来“杠”你。

## 它是怎么“离线 AI”的

它**不是**真正的大模型——因为你要完全不接 AI、不联网。所以这里用的是**本地规则引擎**：

- 一个 `KnowledgeBase.gd` 相当于“大脑”，存放了《逻辑与辩论资料库》里的谬误库、苏格拉底式追问、归谬/通用攻击模板。
- 一个 `DebateEngine.gd` 负责“理解”：用关键词 + 正则**侦测**你输入里的某种逻辑谬误（诉诸大众、诉诸权威、假两难、人身攻击、滑坡、诉诸情感、以偏概全、诉诸传统/自然、复杂问句等），命中就给出**「识别 → 拆解 → 反驳」**三连击；没命中就切换到**苏格拉底式追问 / 通用拆解 / 归谬**。
- 带一个轻量**计分/难度**系统（温和/毒舌/归谬狂魔），让你有“对战”的感觉。

所以你“抛出一个观点”，它“用逻辑漏洞来杠”。这套数据完全取自项目根目录的 `逻辑与辩论资料库/`。

## 各文件

| 文件 | 作用 |
|---|---|
| `project.godot` | 项目配置（已设为手机渲染、竖屏、720×1280） |
| `scenes/Main.tscn` | 主场景（纯 Control + 挂 Main.gd） |
| `scripts/Main.gd` | 搭建 UI + 把输入送进引擎；**可改 UI** |
| `scripts/DebateEngine.gd` | 离线引擎：侦测谬误 → 三连击 / 兜底；**可改难度与逻辑** |
| `scripts/KnowledgeBase.gd` | 全部“大脑”数据：谬误规则、反击模板；**想加内容就改这里** |

## 怎么运行

### 桌面预览（最快）
1. 用 **Godot 4.7.2 stable** 打开本文件夹（`godot_logic_game/project.godot`）。
2. 点 ▶ 运行即可在窗口中玩。

### 手机端（Android）
1. **Godot 4.7.2** → 右上角点击 **安装 Android 构建模板（Build Template）**（若是首次）。
2. `项目 → 导出 → 添加 → Android`。
3. 配置 **Keystore / 签名 / 包名**（首次需建一个 debug 密钥）。
4. 点「导出项目」得 `.apk`，安装到手机即可。输入框在手机上会自动唤起软键盘。

### 手机端（iOS）
- 需 macOS + Xcode，通过 Godot 导出到 Xcode 再打包。逻辑完全一致。

> 真机运行时，**可完全断网**，整个游戏不发起任何网络请求、不调用任何外部 AI——所有“反驳”都来自本地的 `KnowledgeBase.gd`。

## 接招逻辑

- 你说话 → 引擎先扫谬误 → 有就“命中”，给你三连击。
- 你说得像在讲理（含“证据 / 因为 / 所以 / 反例 / 比如…”）→ 引擎会夸你并给分。
- 剩下情况 → 它用苏格拉底式追问 / 拆解 / 归谬接招。

## 怎么拓展（把《资料库》更多内容加进去）

想让它“懂得更多”，只需在 `scripts/KnowledgeBase.gd` 里加数据，不用改引擎：

- 在 `FALLACIES` 里加一个 `{ "name"…, "en"…, "signals"…, "regex"…, "explain"…, "probe"…, "reductio"… }`，即可多识别一种谬误。
- 在 `SOCRATIC` / `ATTACKS` / `REDUCTIO` / `PRAISE` 里加句子，即可让接招更丰富。
- 想接入真实本地 LLM（如 Ollama/llama.cpp）时，把 `DebateEngine.respond()` 换成调用本地推理即可——但那已经是另一个“接 AI”的方向了。
