# 音频替换指南（怎么改音效和背景音）

> 适用版本：v1.4.3+ · 引擎 Godot 4.7.2
> 全套音频：`game/assets/audio/` 共 55 个 OGG（12 BGM + 9 环境音 + 34 音效），22050Hz 单声道。

---

## 一、三个前缀，决定文件的身份

| 前缀 | 用途 | 循环 | 剧本里怎么引用 |
|---|---|---|---|
| `bgm_*` | 背景音乐 | ✅ 自动循环 | `@bgm bgm_unease` |
| `amb_*` | 环境氛围音（雨声/走廊/电流……） | ✅ 自动循环 | `@amb amb_rain` |
| `sfx_*` | 一次性音效（敲门/翻页/惊吓 sting） | ❌ 播一次 | `@sfx sfx_door 0.9`（第二参数音量 0~1） |

**文件名（去掉扩展名）就是 ID**。`bgm_unease.ogg` 的 ID 是 `bgm_unease`。循环、音量层级、混音全部由 `autoload/audio_director.gd` 按前缀自动处理——**换文件不需要改任何代码**。

## 二、替换一首现有的（最常用）

1. 准备好你的音频（推荐 **OGG Vorbis，22050Hz，单声道**，和现全套一致；WAV / MP3 也能用）
2. 转成同名文件覆盖：`game/assets/audio/bgm_unease.ogg`
3. 回到 Godot 编辑器，它会**自动重新导入**；没反应就右键该文件 → **重新导入（Reimport）**
4. 运行游戏，走到引用它的剧情处试听

> 引用点查法：在 `game/story/` 里全局搜 `@bgm bgm_unease` 就知道哪些场景在用它。
> 想临时静音某首，直接把剧本里那行 `@bgm ...` 删掉或换成别的 ID 即可。

## 三、新增一首自己的

1. 文件丢进 `game/assets/audio/`，按前缀命名，如 `bgm_my_theme.ogg`
2. 在剧本（`.avg`）里引用：

```
@bgm bgm_my_theme        # 切背景乐
@sfx my_door_knock 0.8   # 播音效（可带音量）
```

3. 换场景/章节时记得 `@bgm 其他id` 或 `@stopbgm` 切走，BGM 不会自己停。

## 四、音量与平衡

- 玩家侧两层控制：设置面板「总音量 ×（音乐/环境 | 音效）」实时生效
- 引擎内置比例：环境音 = BGM 音量 ×0.75~0.8；打字声更低
- 单条音效微调：`@sfx sfx_slam 1.2`（第二参数可 >1）
- 想改全局比例：`autoload/audio_director.gd` 里 `apply_settings` / `play_amb` 的系数

## 五、常见问题

| 现象 | 处理 |
|---|---|
| `Ogg Vorbis decoding failed` / `Error importing` | ① 确认文件没传坏：跑 `python3 tools/check_audio.py` 自检；② 右键文件 → Reimport；③ 仍不行：关闭编辑器，删除 `game/.godot/` 目录后重开（全量重导入） |
| 换了文件但听到的还是旧的 | 编辑器没重导入 → 右键 → Reimport；或删除 `game/.godot/imported/` 后重启 |
| 想换格式（用 wav/mp3） | 可以：引擎按 `.ogg → .wav → .mp3` 顺序查找同名文件；但注意同名多格式时 OGG 优先 |
| 音效播放被截断 | 正常：8 路复用池，密集音效会复用最旧通道；把最长最重要的音效留足间隔即可 |
| 导出后没声音 | 检查导出预设过滤器是否把 `assets/audio` 排除了（默认包含） |

## 六、批量自检 / 重编码

```bash
# 自检全部音频（结构 + 完整解码）
python3 game/tools/check_audio.py

# 把某个 wav 转成与全套一致的 OGG（22050Hz 单声道）
python3 -c "import soundfile as sf; d,s=sf.read('in.wav'); sf.write('bgm_x.ogg', d, s, format='OGG', subtype='VORBIS')"
```
